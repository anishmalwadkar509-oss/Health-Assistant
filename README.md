# Health-Assistant

A semi-autonomous robot that delivers medication in hospitals and answers health queries using AI speech recognition.

Features
Voice interaction (AssemblyAI + pyttsx3)
Live Streaming (ESP32 CAM)
Blynk App control
Medical delivery assistant
Authors
Harsh S. Phadnis
Anish A. Malwadkar
Published In
International Journal of Scientific Research in Engineering and Management (March 2024)
